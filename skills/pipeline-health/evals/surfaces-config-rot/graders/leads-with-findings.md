If the report contains findings — an adapter that has gone quiet, a gate that
has never fired, documents named but not held — the response must surface them
and say what they mean, rather than only summarising volume. An adapter going
quiet means that court changed its template and its mail is landing unparsed.

Score 0 if it reports only counts while a finding was present, or if it
describes one-way notification traffic as unanswered mail.
